# habit Skin Lab (해빛한방병원 한방피부클리닉) 홈페이지 인수인계

Claude Code에서 이 폴더를 열고 이 파일부터 읽게 하세요. 지금까지의 결정과 앞으로의 방향이 정리되어 있습니다.

## 1. 무엇을 만드는가
- 해빛한방병원(전북 전주시 덕진구, 대표원장 최규현)의 한방피부클리닉 "habit Skin Lab" 전용 홈페이지.
- 병원 본 홈페이지와는 별개 사이트입니다. 서로 쉽게 오갈 수 있어야 합니다(병원 첫 화면에서 두 사이트를 양분할로 선택).
- 목표: 감각적이고 세련된 최신 피부과 느낌, 상담·예약 전환. 큰 이미지·영상 비중을 높입니다.

## 2. 새 방향 (이번 업그레이드의 핵심)
- 메인 히어로에 젊고 예쁜 여성 모델 사진(또는 영상)을 넣습니다.
- 전체 랜딩 페이지에 큰 영상과 이미지를 많이 사용합니다.
- 틀(레이아웃)을 많이 바꿀 예정입니다. 기존 시안은 참고용으로 보고, 필요하면 구조를 새로 짜도 됩니다.
- 사진·영상 용량이 크므로 이미지 최적화(webp/avif, 지연 로딩), 영상은 압축·자막 없는 짧은 루프를 권장합니다.

## 3. 지켜야 할 결정 사항
- 가격은 공개하지 않습니다. "상담 후 안내"로 표기합니다. 가격 줄은 나중에 추가하기 쉽도록 카드 구조만 유지합니다.
- 의료광고 주의: 효과 보장·과장 표현 금지, 시술 전후 사진은 회원 전용 또는 심의를 거친 경우만, 이벤트·할인 문구는 심의 후 사용.
- 환자·모델 사진은 초상권 동의를 확인합니다. 모델 사진이 실제 시술 결과로 오인되지 않게 합니다.
- 톤: 환자에게 말하는 따뜻하고 설득력 있는 문장.
- 다래한방병원 홈페이지는 **구조만** 참고했습니다(메뉴 구성, 섹션 순서, 이미지 배치 방식). 문구·사진·로고는 쓰지 않았고, 쓰면 안 됩니다.

## 11. 진행 현황 (2026-11-04)
- 기술 방식: **의존성 없는 정적 사이트 + Node 빌드 스크립트**로 시작했습니다 (`site/`). 공통 헤더·푸터·오시는 길·팝업은 `site/src/partials/`에서 한 번만 관리합니다. 자세한 사용법은 `site/README.md`.
- 메인을 새 틀로 다시 짰습니다: 전체 화면 히어로(모델 사진/영상 자리, 밝은 아이보리 톤) → 문구 흐름 띠 → 소개(실제 접수 데스크 사진) → 고민별 큰 이미지 타일 6개 → 시그니처 프로그램 12개(분류 필터, 카드 하단 "상담 후 안내") → 전체 폭 영상 밴드(진단→재생관리 4단계) → 큰 사진 + 글 3단 → 의료진 배너 → 칼럼 슬라이더 → 사진 배경 상담 CTA → 오시는 길.
- 서브페이지 10개는 기존 문구를 그대로 옮기고, 서브 히어로를 큰 이미지 + 밝은 톤으로 바꿨습니다. `확인 필요` 표시는 그대로 유지했습니다.
- 모바일: 햄버거 메뉴, 하단 고정 상담 바(전화·카카오톡·네이버 예약), 고민 타일·필터 가로 스크롤.
- 다음 할 일: 모델 사진·영상 확보 후 교체, `site/config.json`의 빈 링크(`"#"`) 채우기, 시술 페이지 장비 블록에 장비 사진 자리 추가, 폼·로그인·관리자 기능(호스팅 결정 후).
